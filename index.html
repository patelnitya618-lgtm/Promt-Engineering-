What is AI?

Artificial Intelligence is technology that enables computers to perform tasks that normally require human intelligence.

Examples

Chatbots, voice assistants, recommendation systems, image tools and coding assistants.

Why it matters

AI can help students learn, create, solve problems and work faster — when we give clear instructions.

Slide 03 / 10

What is a Prompt?

A prompt is the instruction, question or information we give to an AI system.

Simple prompt

Explain Java.

Very broad. AI has little direction.

Clear prompt

Explain Java inheritance to a diploma student in simple English with one example.

The AI gets a clear audience, topic and requirement.

Slide 04 / 10

What is Prompt Engineering?

Prompt engineering means designing and improving instructions so AI understands exactly what we need.

Vague request ↓ Add context ↓ Define the task ↓ Add requirements ↓ Specify the output ↓ Better result
Slide 05 / 10

The Prompt Formula

Remember these five parts when writing an important prompt.

ROLE
CONTEXT
TASK
REQUIREMENTS
OUTPUT
Act as a college tutor. I am a diploma student learning Java. Explain inheritance. Include definition, types and one example. Format it as a 5-mark answer in simple English.

Slide 09 / 10

Mistakes & Verification

Common mistakes

Too vague • no context • no audience • no format • asking too many things at once.

Always verify

AI can produce incorrect facts, calculations, code or outdated information. Check important answers before using them.

Ask → Check → Improve → Verify
